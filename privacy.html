ttolttol 개인정보처리방침

시행일: 2026년 11월 17일

1. 누가 쓰는 앱인가

ttolttol은 소유자 한 사람이 자기 컴퓨터에서 직접 실행하는 개인용 프로그램입니다. 일반에 제공하지 않으며, 소유자 외의 사용자는 없습니다. 이 방침은 그 소유자의 Google 계정 데이터를 앱이 어떻게 다루는지 설명합니다.

2. 접근하는 데이터

  • Gmail: 소유자가 보내라고 승인한 메일의 발송, 받은 메일의 목록과 내용 읽기(읽기 전용).
  • Google 캘린더: 소유자 캘린더의 일정 조회·추가·변경·삭제.
  • Google 계정의 메일 주소(연결된 계정 표시용).

3. 데이터를 쓰는 목적

소유자가 지시한 일을 수행하고 그 결과를 소유자에게 보여 주는 데에만 씁니다. 광고, 판매, 통계, 다른 사람의 프로필 작성에 쓰지 않습니다.

4. 보관 위치와 기간

앱이 읽은 데이터와 로그인 정보는 소유자의 컴퓨터에만 저장됩니다. 앱 운영자가 따로 두는 서버는 없습니다. 소유자는 언제든 자기 컴퓨터에서 해당 파일을 지울 수 있습니다.

5. 제3자 제공

데이터를 판매하거나 제3자에게 넘기지 않습니다. 다만 소유자가 문서 작성·요약 같은 작업을 명시적으로 지시한 경우에 한해, 그 작업에 필요한 내용이 소유자가 직접 계약해 설정한 AI 서비스 제공자(API)로 전송되어 처리될 수 있습니다. 소유자가 지시하지 않은 데이터는 보내지 않습니다.

6. Google 사용자 데이터의 사용 제한

이 앱이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

7. 접근 권한 철회

소유자는 Google 계정의 보안 설정에서 언제든 이 앱의 접근 권한을 취소할 수 있습니다. 취소하면 앱은 더 이상 Google 데이터에 접근하지 못합니다.

8. 문의

이 방침에 관한 문의는 이 페이지가 올라 있는 GitHub 저장소의 이슈로 남길 수 있습니다.

English summary: ttolttol is a single-user personal assistant run by its owner on the owner's own computer. It accesses the owner's Gmail (send, read-only viewing) and Google Calendar (events) only to carry out the owner's instructions. Data stays on the owner's computer; it is not sold or shared. Content is sent to AI API providers configured by the owner only when the owner explicitly asks for a task that requires it. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time in the Google Account security settings.
